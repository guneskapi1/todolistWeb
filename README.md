# Yapılacaklar Listesi (TodoListWeb)

Bu proje, sadece **HTML**, **CSS** ve **JavaScript** kullanılarak geliştirilmiş basit bir yapılacaklar listesi (to-do list) uygulamasıdır. Veriler tarayıcının **localStorage** özelliği ile saklanır, yani sayfa kapatılsa bile görevler kaybolmaz.

## Özellikler

-  Görev ekleme (başlık, açıklama ve tarih ile)
-  Görev tamamlama (checkbox ile işaretleme)
-  Görev silme
-  Arama: Başlık, açıklama ve tarihlerde arama
-  Filtreleme: Tüm görevler, tamamlananlar, tamamlanmayanlar
-  Tarihe göre otomatik sıralama
-  localStorage ile veri saklama

## Proje Yapısı

todolistweb/
├── index.html # Ana HTML sayfası
├── style.css # Uygulamanın stilleri
└── script.js # Tüm görev yönetim mantığı (JS)

## Kullanılan Teknolojiler

- HTML5
- CSS3
- JavaScript (Vanilla)
- localStorage API

## Nasıl Kullanılır?

1. Bu repository'yi klonlayın veya ZIP olarak indirin.
2. `index.html` dosyasını tarayıcınızda açın.
3. Görevlerinizi ekleyin, yönetin ve yönetin!
